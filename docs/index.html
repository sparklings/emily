Core Capabilities

옵시디언 맞춤형 지능형 기능들

🛡️

100% 무손실 문법 마스킹

YAML 프론트매터, 옵시디언 [[위키링크]], #태그, LaTeX 수식($...$), 콜아웃 블록(> [!note]), 코드 블록을 고유 UUID 토큰으로 완전 격리 마스킹한 후 AI 연산을 수행하여 서식 깨짐을 원천 차단합니다.

✍️

종결어미 및 문체 일관성 검사기

긴 문서를 집필할 때 혼재되기 쉬운 종결어미(하십시오체, 해라체, 해요체)를 정밀 감지하고 통일합니다. 인용구, 헤딩 제목, 코드 내부는 예외 구역으로 안전하게 보존됩니다.

🌐

맥락 인식 전문 번역 (3대 모드)

선택 영역 번역, 문서 전체 번역뿐만 아니라 논문 및 외신 독해에 최적인 단락별 1:1 대조 병렬 번역(Paragraph Bilingual)을 지원합니다. 출발어와 도착어가 같을 경우 스마트 "편집" 모드로 자동 전환됩니다.

📚

사용자 정의 용어집 (Glossary)

분야별 전문 용어나 회사/프로젝트 고유의 기술 단어를 등록해 두면, LLM이 문맥과 상관없이 사전에 정의된 도착어 용어로 100% 일관되게 치환·번역하도록 프롬프트에 자동 주입합니다.

💻

기기 프로필 기반 스마트 엔드포인트 관리

집/회사/연구실 등 여러 PC(1~4호+)의 호스트명을 자동 식별하여 각 기기에 맞는 로컬 프록시 포트와 API 키를 자동 선출합니다. 포트/키 자동 진단(Auto-Probe)으로 원클릭 복구를 지원합니다.

🔍

대화형 Diff 검토 & 제로 토큰 재오픈

Needleman-Wunsch 알고리즘 기반의 인터랙티브 대조 뷰어를 제공합니다. 변경점을 한눈에 확인하고 선택 적용할 수 있으며, 이전 작업 히스토리는 추가 토큰 소모 없이 언제든 다시 열어 재검토할 수 있습니다.

Quick Installation

플러그인 설치 방법

  1. 옵시디언 커뮤니티 플러그인에서 BRAT (Beta Reviewers Auto-update Tester)를 검색하여 설치 및 활성화합니다.
  2. 명령어 팔레트(Ctrl+P / Cmd+P)에서 BRAT: Add a beta plugin for testing을 실행합니다.
  3. 저장소 주소란에 아래 링크를 입력합니다:
https://github.com/sparklings/emily

설치가 완료되면 설정 > 커뮤니티 플러그인 목록에서 Assistant Emily를 켜주시면 됩니다.

  1. GitHub Releases 페이지에서 최신 main.js, manifest.json, styles.css 파일을 다운로드합니다.
  2. 본인의 옵시디언 볼트 폴더 내 .obsidian/plugins/assistant-emily/ 디렉토리를 생성하고 위 3개 파일을 넣습니다.
  3. 옵시디언을 재시작하거나 설정 > 커뮤니티 플러그인 > 새로고침 후 활성화합니다.
🔒

100% 로컬 직접 통신 및 프라이버시 원칙

Assistant Emily는 별도의 자체 중계 서버를 운영하지 않습니다. 사용자의 볼트 데이터는 오직 사용자가 직접 지정한 AI 백엔드(OpenAI, Ollama, LM Studio, FreeLLMAPI 등)로만 직접 암호화 통신되며, 일체의 원격 분석(Telemetry)이나 사용자 추적 코드를 포함하지 않습니다.
