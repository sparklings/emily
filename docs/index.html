옵시디언 번역의 완성: 6대 스마트 번역 기능

일반 웹 번역기가 해결하지 못하는 옵시디언 마크다운 특화 번역을 지원합니다. 원문과 번역문을 나란히 비교하는 1:1 대조 번역부터 개발자를 위한 코드 주석 번역까지, 마크다운 문법을 완벽히 보호합니다.

추천 1위 · 논문 & 기사 완독

📖 단락별 1:1 대조 병렬 번역

문서 전체를 문단 단위로 분할하여, 각 원문 문단 바로 아래 줄에 번역 문단을 1:1로 나란히 배치합니다. 영문 기술 블로그, 아카이브 논문, 외신 기사를 원문과 번역문을 동시에 대조하며 읽을 수 있는 가장 강력한 옵시디언 번역 모드입니다.

100% 무손실 완전 번역

🌐 문서 전체 무손실 번역

문서 전체의 제목과 본문을 대상 언어로 번역하되, 상단 YAML 메타데이터, [[위키링크]], LaTeX 수식($...$), #태그, 콜아웃 블록은 고유 UUID 토큰으로 격리하여 1글자의 서식 손실도 없이 원본 그대로 보존합니다.

원클릭 블록 번역

🎯 선택 영역 즉시 번역

에디터에서 마우스나 키보드로 드래그한 특정 단락만 즉시 번역합니다. 원문 뒤 덧붙이기(Append), 새 번역 파일 생성(New File), 현재 문서 덮어쓰기(Overwrite) 중 원하는 원문 보존 방식을 자유롭게 선택할 수 있습니다.

어색한 번역투 교정

✨ 동일 언어 스타일 편집 모드

출발어와 도착어가 같을 경우(예: 한국어 ➔ 한국어) 자동으로 스타일 편집 모드로 전환됩니다. 번역투가 남아있는 거친 문장을 매끄럽게 다듬고, 학술적(Academic), 정중한(Polite), 친근한(Casual) 톤으로 문체를 정합화합니다.

개발자 맞춤

💻 코드 블록 내부 주석 번역

코드 블록(```) 내부의 실행 가능한 소스코드는 절대 건드리지 않고, 한 줄 주석(//, #)과 블록 주석(/* ... */)만 똑똑하게 식별하여 도착어(한국어 등)로 안전하게 번역합니다.

전문 용어 오역 방지

📚 사용자 정의 번역 용어집 (Glossary)

프로젝트 고유의 기술 단어나 사내 전문 용어를 등록해두면, AI가 문맥에 휘둘리지 않고 사전 정의된 용어로 100% 일관되게 번역하도록 시스템 프롬프트에 자동 주입합니다.

Core Capabilities

옵시디언 맞춤형 6대 핵심 기능

🛡️

100% 무손실 문법 마스킹

YAML 프론트매터, 옵시디언 [[위키링크]], #태그, LaTeX 수식($...$), 콜아웃 블록(> [!note]), 코드 블록을 고유 UUID 토큰으로 완전 격리 마스킹한 후 AI 연산을 수행하여 서식 깨짐을 원천 차단합니다.

✍️

종결어미 및 문체 일관성 검사기

긴 문서를 집필할 때 혼재되기 쉬운 종결어미(하십시오체, 해라체, 해요체)를 정밀 감지하고 일관되게 통일합니다. 인용구, 헤딩 제목, 코드 내부는 예외 구역으로 안전하게 보존됩니다.

🌐

맥락 인식 전문 번역 (3대 모드)

선택 영역 번역, 문서 전체 번역뿐만 아니라 논문 및 외신 독해에 최적인 단락별 1:1 대조 병렬 번역(Paragraph Bilingual)을 지원합니다. 출발어와 도착어가 같을 경우 스마트 "스타일 편집" 모드로 자동 전환됩니다.

📚

사용자 정의 용어집 (Glossary)

분야별 전문 용어나 회사/프로젝트 고유의 기술 단어를 등록해 두면, LLM이 문맥과 상관없이 사전에 정의된 도착어 용어로 100% 일관되게 치환·번역하도록 프롬프트에 자동 주입합니다.

💻

단일 통합 대시보드 & 다중 기기 독립 바인딩

집/회사 등 여러 PC에서 OneDrive로 볼트를 동기화해도 각 PC별 독립 프로필(포트 및 API 키)을 로컬에 안전하게 바인딩하여 클라우드 충돌을 원천 차단합니다. 콤팩트 모달 편집 및 401 오류 자동 진단(Auto-Probe) 자가 치유를 지원합니다.

🔍

대화형 Diff 검토 & 제로 토큰 재오픈

Needleman-Wunsch 알고리즘 기반의 인터랙티브 대조 뷰어를 제공합니다. 변경점을 한눈에 확인하고 선택 적용할 수 있으며, 이전 작업 히스토리는 추가 토큰 소모 없이 언제든 다시 열어 재검토할 수 있습니다.

Quick Installation

플러그인 설치 방법

Assistant Emily는 Obsidian 공식 커뮤니티 플러그인으로 정식 출시되었습니다. 공식 커뮤니티 플러그인 웹페이지로 바로 이동하거나, 옵시디언 앱 내에서 원클릭으로 즉시 설치하실 수 있습니다.

🔗 Assistant Emily - Obsidian Plugin 공식 페이지 바로가기 ✨ 옵시디언 앱에서 즉시 열기 (1-Click Install)
  1. 옵시디언을 실행하고 좌측 하단 설정(Settings ⚙️) > 커뮤니티 플러그인(Community plugins)으로 이동합니다.
  2. '제한 모드(Restricted mode)'가 켜져 있다면 [제한 모드 끄기(Turn off)]를 선택합니다.
  3. 커뮤니티 플러그인 목록의 [탐색(Browse)] 버튼을 클릭합니다.
  4. 검색창에 Assistant Emily를 검색합니다.
  5. 검색 결과에서 Assistant Emily를 선택하고 [설치(Install)]를 누른 후, 설치가 완료되면 [활성화(Enable)] 버튼을 클릭합니다.
  6. 좌측 리본 바(✨ 아이콘) 또는 명령어 팔레트(Ctrl+P / Cmd+P)에서 Assistant Emily: Open Sidebar를 실행하여 옵시디언 번역 및 교열을 즉시 시작할 수 있습니다.

인터넷 연결이 차단된 오프라인 환경 또는 사내 폐쇄망에서 수동으로 설치해야 하는 경우 사용합니다.

  1. GitHub Releases 페이지에서 최신 main.js, manifest.json, styles.css 파일을 다운로드합니다.
  2. 본인의 옵시디언 볼트 폴더 내 .obsidian/plugins/assistant-emily/ 디렉토리를 생성하고 위 3개 파일을 넣습니다.
  3. 옵시디언을 재시작하거나 설정 > 커뮤니티 플러그인 > 새로고침 후 활성화합니다.
🔒

100% 로컬 직접 통신 및 프라이버시 원칙

Assistant Emily는 별도의 자체 중계 서버를 운영하지 않습니다. 사용자의 볼트 데이터는 오직 사용자가 직접 지정한 AI 백엔드(OpenAI, Ollama, LM Studio, FreeLLMAPI 등)로만 직접 암호화 통신되며, 일체의 원격 분석(Telemetry)이나 사용자 추적 코드를 포함하지 않습니다.

Frequently Asked Questions

자주 묻는 질문 (FAQ)

옵시디언 번역 시 마크다운 서식이나 위키링크가 깨지지 않는 플러그인은 무엇인가요?

Assistant Emily는 옵시디언 번역 시 YAML 헤더, [[위키링크]], LaTeX 수식($...$, $$...$$), 콜아웃을 독자적인 UUID 토큰 격리 마스킹 엔진으로 보호한 후 연산하므로, 1글자의 서식 손실도 없이 100% 원본 그대로 보존하며 번역하는 공식 커뮤니티 플러그인입니다.

옵시디언 번역에서 원문과 번역문을 1:1 단락별로 대조(병기)하며 볼 수 있나요?

네, Assistant Emily의 '단락별 1:1 대조 병기(Paragraph Bilingual)' 번역 모드를 사용하면 문서 전체를 문단별로 자동 분할하여 각 원문 문단 바로 아래 줄에 번역 문단을 1:1로 나란히 배치합니다. 해외 최신 논문, 영문 기술 블로그, 외신 기사를 원문과 번역문을 비교하며 읽는 데 가장 최적화되어 있습니다.

DeepL이나 구글 번역 대신 Assistant Emily로 옵시디언 번역을 해야 하는 이유는 무엇인가요?

일반 DeepL이나 웹 번역기에 복사/붙여넣기하면 [[노트링크]]가 끊어지고 YAML 프론트매터의 줄바꿈이 사라지며, 수식 기호가 훼손됩니다. Assistant Emily는 옵시디언 에디터 내부에서 클릭 한 번으로 무손실 번역을 실행하며, 코드 주석만 선택 번역하거나 사용자 정의 용어집(Glossary)을 주입할 수 있고 로컬 LLM(Ollama)으로 완전 무료 오프라인 번역도 지원합니다.

Assistant Emily란 어떤 플러그인인가요?

Assistant Emily는 옵시디언(Obsidian) 전용으로 개발된 공식 커뮤니티 AI 플러그인입니다. 긴 마크다운 문서를 집필할 때 맞춤법 교열, 종결어미 일관성 교정, 1:1 대조 번역을 제공하며, 특히 YAML 프론트매터, [[위키링크]], LaTeX 수식, 콜아웃 등 옵시디언 고유 문법을 100% 무손실 보존하는 것이 가장 큰 특징입니다.

Ollama, LM Studio 등 로컬 AI 모델로도 옵시디언 번역이 가능한가요?

네, 완벽하게 지원합니다. Ollama(포트 11434)나 LM Studio(포트 1234) 등 로컬 머신에서 구동되는 LLM과 직접 연결하여 인터넷 연결 없이도 안전하고 완전 무료로 옵시디언 번역을 수행할 수 있습니다. 집 노트북, 회사 PC 등 여러 기기 환경에 맞춰 포트와 API 키를 자동 선출하는 스마트 기기 프로필 관리 기능도 내장되어 있습니다.

개인정보와 볼트 데이터는 안전하게 보호되나요?

Assistant Emily는 개발자나 제3자가 운영하는 어떠한 중계 서버도 거치지 않습니다. 모든 데이터 통신은 사용자 데스크톱에서 사용자가 직접 설정한 엔드포인트(로컬 머신 또는 OpenAI 계정)로만 직접 전송되며, 일체의 원격 분석(Telemetry) 및 사용자 추적 코드가 전혀 포함되어 있지 않습니다.

Assistant Emily는 무료로 사용할 수 있나요?

네, Assistant Emily는 MIT 오픈소스 라이선스 하에 배포되는 100% 완전 무료 플러그인입니다. 플러그인 자체에 대한 구독료나 기능 제한이 전혀 없으며, 로컬 LLM을 사용할 경우 추가 비용 없이 완전 무료로 평생 사용하실 수 있습니다.

Obsidian Translation & Proofreading with Assistant Emily

✨ Intelligent, Lossless Markdown Proofreading & Translation

Assistant Emily is the premier Obsidian Community Plugin designed to solve formatting corruption during markdown translation. It preserves Obsidian-native YAML frontmatter, [[Wikilinks]], LaTeX formulas, and callouts with 100% byte-level accuracy while delivering professional proofreading and context-aware bilingual translation.

  • 100% Syntax Preservation: UUID token isolation keeps Obsidian wikilinks and metadata completely intact during translation.
  • Paragraph Bilingual Translation: Translates foreign articles or research papers side-by-side (1:1 sentence matching).
  • Interactive Character-Level Diff: Powered by the Needleman-Wunsch algorithm for granular change review and selective merging.
  • Local LLM & Privacy First: Zero telemetry, direct encrypted streaming to Ollama, LM Studio, or OpenAI-compatible proxies.
  • Unified Dashboard & Multi-Device Profiles: Independent local device binding eliminates OneDrive sync collisions with compact modal editing and auto-probe self-healing.
  • One-Click Sidebar Refresh: Instantly resets work state, aborts running requests, and cleans UI components.
