# Troubleshooting & Diagnostics Guide
### 장애 진단 및 문제 해결 가이드

본 문서는 **Assistant Emily** 사용 중 발생할 수 있는 네트워크 통신 오류, 컨텍스트 한도 초과, 번역 누출 현상, 그리고 UI 레이아웃 문제를 빠르게 진단하고 해결하기 위한 공식 가이드입니다.

---

## 1. 주요 장애 증상 및 빠른 조치표

| 장애 증상 | 주요 원인 | 핵심 조치 방법 |
| :--- | :--- | :--- |
| **502 Bad Gateway / 통신 실패** | LLM Proxy 서버 일시 장애 또는 방화벽 차단 | 상단 팝업 Notice 억제 확인 후 프록시 상태 점검 |
| **413 Context / Chunk 초과** | 단일 요청 토큰 한도 초과 | 청킹 임계값 1,800자 자동 분할 적용 여부 확인 |
| **목차 타임스탬프가 한 줄로 뭉개짐** | 구버전 마스커 사용 | v1.1.0 업데이트 및 `TOCTIME` 마스킹 잠금 확인 |
| **번역 중 중국어 간체 어휘 노출** | 다국어 오픈소스 LLM의 교차 언어 누출 | `Strict Pure Korean` 자동 정제 엔진 가동 확인 |
| **사이드바에서 버튼 글자가 겹침** | 사이드바 너비 협소 (<380px) | 반응형 콤팩트 22px 아이콘 전용 모드 전환 확인 |

---

## 2. 세부 진단 및 해결 절차

### 2.1 LLM 프록시 502 Bad Gateway 및 네트워크 미도달
* **증상**: 작업 실행 시 상단에 반복적으로 팝업 경고가 뜨거나 진행 단계 2에서 멈춤.
* **진단 원인**:
  * FreeLLMAPI 또는 자체 구축 리버스 프록시 서버의 과부하로 인한 일시적 게이트웨이 오류.
  * 로컬 Ollama 또는 LM Studio 백엔드가 백그라운드에서 종료됨.
* **해결책**:
  1. Assistant Emily v1.1.0은 502/네트워크 오류 발생 시 사용자를 방해하는 상단 `Notice` 팝업을 전면 억제하고, 사이드바 타임라인의 **Step 2 에러 카드(`.is-proxy-error`)** 에 원인을 상세히 표시합니다.
  2. 로컬 백엔드 사용 시: 터미널에서 `ollama serve` 명령으로 서비스가 실행 중인지 확인하고 `curl http://localhost:11434/api/tags`로 응답 여부를 테스트합니다.
  3. 클라우드 프록시 사용 시: 설정 탭에서 [연결 테스트] 버튼을 클릭하여 엔드포인트 URL 및 API 키 유효성을 확인합니다.

---

### 2.2 입력 분량 및 토큰 컨텍스트 초과 (413 Payload Too Large)
* **증상**: 에밀리 지시창에 매우 긴 요구사항을 입력하거나 30,000자 이상의 대용량 문서를 작업할 때 오류 발생.
* **진단 원인**:
  * LLM 모델의 입력 컨텍스트 윈도우(Context Window)를 초과함.
* **해결책**:
  1. 지시사항(`customPrompt`)은 핵심 요구사항 위주로 간결하게 작성합니다. (권장: 300자 이내)
  2. 대용량 문서의 경우 Assistant Emily의 **1,800자 스마트 청킹** 이 자동으로 작동하므로, 번역 범위를 `전체 문서 번역(all)`으로 설정하여 실행하면 문서 전체가 안전하게 순차 분할 완역됩니다.

---

### 2.3 중국어 간체 토큰 누출 현상 (Cross-Lingual Leakage)
* **증상**: 한국어 번역 결과물에 `我们所拥有的`, `由于`와 같은 중국어 간체 단어가 섞여 나옴.
* **진단 원인**:
  * DeepSeek, Qwen 등 중국어-영어 말뭉치 비중이 높은 다국어 모델에서 잠재 공간(Latent Space) 간섭으로 인해 한국어 조사 앞에 중국어 어휘가 잘못 출력됨.
* **해결책**:
  1. Assistant Emily v1.1.0에는 **코드 레벨 중국어 간체 자동 정제 필터** 가 기본 내장되어 있어, 번역 수신 즉시 해당 어휘를 자연스러운 한국어(`우리가 가진 것` 등)로 자동 변환합니다.
  2. 모델 교체가 가능한 경우 프롬프트 가드레일 준수도가 높은 모델(`qwen2.5:14b` 이상 또는 `gpt-4o-mini`)을 권장합니다.

---

### 2.4 미번역 영어 문단 누출 방지 (Untranslated English Interception)
* **증상**: 번역이 완료되었으나 본문 중간의 일부 단락이 영어 원문 그대로 남아 있음.
* **진단 원인**:
  * 무료 프록시의 간헐적 타임아웃이나 모델의 번역 생략 현상.
* **해결책**:
  1. Assistant Emily는 청크 수신 즉시 **한글 비율(Korean Ratio) 분석 엔진** 을 가동합니다.
  2. 200자 이상의 텍스트 블록 중 라틴 문자 비율이 75%를 초과하면 번역 실패로 간주하고, 강제 직역 지시 프롬프트를 사용하여 1회 자동 자가 치유 재시도를 수행합니다.

---

### 2.5 좁은 사이드바 환경에서의 취소 버튼 글자 잘림
* **증상**: 옵시디언 오른쪽 사이드바 너비를 좁혔을 때 [❌ 작업 취소] 버튼의 글자가 줄바꿈되거나 영역을 벗어남.
* **해결책**:
  1. v1.1.0 반응형 레이아웃 엔진이 사이드바 폭을 실시간 감지하여 380px 미만일 경우 텍스트를 자동으로 숨기고 **22px 콤팩트 아이콘 전용 모드** 로 전환합니다.
  2. 마우스를 올리면 툴팁(`title` 및 `aria-label`)을 통해 기능 안내가 온전히 제공됩니다.
