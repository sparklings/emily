# [제4편] 전문 AI 마크다운 교열 및 실시간 대조 검토 모달 활용 매뉴얼

> 번역을 마쳤거나 직접 작성한 마크다운 문서의 품질을 한 차원 높이고 싶으신가요? **Assistant Emily** 는 맞춤법, 문법, 문맥 흐름을 정밀 교열하며, 원문과 수정문을 나란히 비교하고 수정한 내용을 에디터 화면에 즉각 실시간 반영할 수 있는 인터랙티브 대조 검토 모달을 제공합니다.

---

## 📌 교열 파이프라인 흐름도

```mermaid
flowchart TD
    A["1. 마크다운 문서 또는 특정 문단 선택"] --> B["2. 교열 옵션 활성화<br/>(맞춤법 / 문법 / 문맥 가독성)"]
    B --> C["3. 교열 실행 및 AI 분석"]
    C --> D["4. 대조 검토 모달 오픈<br/>- 좌: 원본 텍스트 vs 우: 교열 결과<br/>- 편집자가 직접 내용 추가/수정"]
    D --> E["5. [문서에 수정 내용 저장] 클릭"]
    E --> F["6. 활성 에디터 본문 즉시 교체 치환 &<br/>사이드바 롤링 세션 이력 동기화 완료"]
```

---

## 1단계: 3대 교열 도구 활성화 및 설정

우측 사이드바의 **[마크다운 교열 & 스타일링]** 아코디언을 열면 3가지 독립 교열 도구를 자유롭게 조합할 수 있습니다:

1. ** 맞춤법 검사 (Spelling Correction)**
   * 띄어쓰기 오류, 오탈자, 표준어 규정 위반을 교정합니다.
   * 전문 기술 용어(예: Docker, Kubernetes, PyTorch)는 임의로 바꾸지 않고 고유명사로 보호합니다.
2. **문법 교정 (Grammar Refinement)**
   * 주어-서술어 호응 불일치, 불필요한 피동/이중 피동 표현, 조사 오용을 교정합니다.
3. **문맥 및 가독성 다듬기 (Contextual Flow)**
   * 문장이 지나치게 길거나 만연체인 경우 간결하고 명확한 문장으로 분리 및 윤문합니다.
   * 단락 간의 논리적 연결을 매끄럽게 보정합니다.

---

## 2단계: 교열 작업 실행 (단축키 vs 사이드바 폼)

문서 작업 중 마주치는 상황에 따라 2가지 방식으로 교열을 실행할 수 있습니다:

### 1. 단축키 및 에디터 컨텍스트 메뉴를 통한 빠른 선택 교열
* **에디터 작업 흐름 유지**: 사이드바를 열고 옵션을 일일이 조작할 필요 없이 키보드 입력만으로 빠르게 교열할 수 있습니다.
* **실행 방법**:
  1. 에디터에서 교열할 외국어/한국어 문장이나 문단을 드래그 선택합니다.
  2. 마우스 우클릭 후 **`Assistant Emily: 선택 영역 빠른 교열`** 을 선택하거나, `설정 > 단축키` 에서 지정한 단축키(예: `Alt + Shift + C`)를 누릅니다.
  3. 백그라운드 태스크 큐에 작업이 등록되며, 분석이 완료되는 즉시 대조 검토 창이 열리거나 설정된 보존 방식에 따라 에디터에 안전하게 치환됩니다.

### 2. 사이드바 제어창을 통한 커스텀 지시 및 전체 문서 교열
* **특정 문단 정밀 교열**:
  1. 에디터에서 교열할 문단을 마우스로 드래그 선택합니다.
  2. 사이드바의 지시사항 입력창(`customPrompt`)에 추가 요청사항(예: "더 정중한 어조로", "블로그 독자 친화적으로", "기술 용어 영문 병기")을 기입합니다.
  3. **[작업 시작하기]** 버튼(단축키: `Ctrl + Enter` )을 누릅니다.
* **문서 전체 교열**:
  * 선택 영역 없이 문서에 커서만 둔 상태에서 실행하면 문서 전체 제목과 문단을 종합적으로 분석합니다.

## 3단계: 인터랙티브 대조 검토 모달 (`TranslationDiffModal` / `ProofreadDiffModal`)

작업이 완료되면 직관적인 좌우 2분할 대조 검토 창이 나타납니다.

```
┌────────────────────────────────────────────────────────────────────────┐
│ 🔍 Assistant Emily: 번역 결과 대조 검토 및 교정                           │
├──────────────────────────────────┬─────────────────────────────────────┤
│ 📄 원본 텍스트                     │ ✨ AI 번역/교열 결과 (직접 편집 가능)  │
├──────────────────────────────────┼─────────────────────────────────────┤
│ Artificial Intelligence is       │ 인공지능은 소프트웨어가             │
│ transforming how software is     │ 구축되는 방식을                     │
│ built.                           │ 변화시키고 있습니다.                │
│                                  │                                     │
│                                  │ [편집자가 여기에 추가 보완 문장을     │
│                                  │  직접 입력할 수 있습니다.]          │
├──────────────────────────────────┴─────────────────────────────────────┤
│ [취소]                   [클립보드 복사]        [문서에 수정 내용 저장] (Primary) │
└────────────────────────────────────────────────────────────────────────┘
```

### 주요 검토 기능
1. **좌우 대조 비교**: 원문(좌측)과 AI 번역/교열 결과(우측)를 한눈에 대조하여 누락된 내용이나 어색한 표현이 없는지 점검합니다.
2. ** 직접 편집 기능**: 우측 결과창은 단순 뷰어가 아닌 ** 편집 가능한 텍스트 에디터** 입니다. 번역된 문장에 추가 설명을 덧붙이거나 문맥을 직접 다듬을 수 있습니다.
3. ** 상황 인지형 프라이머리 버튼**:
   * 보존 전략이 `append` (원문 아래 덧붙이기)인 경우 ➔ **`문서에 수정 내용 저장`**
   * 보존 전략이 `overwrite` (덮어쓰기)인 경우 ➔ **`문서에 수정 내용 덮어쓰기`**
   * 보존 전략이 `new_file` 인 경우 ➔ **`새 파일로 저장`**

## 4단계: 문서 화면 실시간 즉각 반영 및 세션 동기화

수정 작업을 마친 뒤 **`[문서에 수정 내용 저장]`** 버튼을 클릭하면 다음과 같은 동기화 파이프라인이 즉시 가동됩니다:

1. ** 에디터 본문 실시간 즉시 치환**:
   * 플러그인이 현재 활성 마크다운 에디터 화면(버퍼)에서 기존에 삽입되었던 번역문을 정밀 탐색하여, 사용자가 직접 수정한 최신 텍스트로 즉각 치환합니다.
   * 사용자가 수동으로 복사-붙여넣기할 필요가 전혀 없습니다.
2. **사이드바 세션 이력 및 캐시 동기화**:
   * 우측 사이드바 하단의 세션 카드(`RollingSessionData`) 내부 데이터가 사용자의 수정본으로 자동 갱신됩니다.
   * 나중에 사이드바에서 **`[번역 결과 대조 검토]`** 버튼을 다시 열더라도 방금 편집했던 내용이 100% 무손실 상태로 그대로 보존되어 있습니다.

## 5단계: 4단계 액션 중심 세션 뷰 및 이력 관리

사이드바 하단에는 최근 작업한 번역 및 교열 작업이 Antigravity 스타일의 **4단계 무경계 세션 뷰** 로 깔끔하게 정돈됩니다:

1. **통합 세션 구분선 헤더**:
   * `──────── 작업 세션 #N · ● 교열/번역 완료 (시간) ∨ ────────`
   * 상단 헤더를 클릭하여 해당 세션의 액션 및 텔레메트리 영역을 자유롭게 접고 펼칠 수 있습니다.
2. **작업 대상 파일 포커스 링크**:
   * 세션 상단에 `• 원본문서.md` 인라인 불릿 링크가 제공됩니다.
   * 다른 노트를 보고 있는 상태에서도 이 링크를 클릭하면 해당 작업 대상 문서 탭으로 즉각 포커스가 전환됩니다.
3. **선택 옵션 요약**:
   * 번역 범위, 보존 방식, 맞춤법/문법 교열 여부 등 당시 적용되었던 파라미터가 1줄 요약으로 제공됩니다.
4. **다이렉트 원클릭 액션 버튼**:
   * 사이드바에 수천 자의 긴 마크다운 본문을 길게 나열하는 대신, 직관적인 3가지 액션 링크를 인라인으로 제공합니다:
     * **`[대조 검토 ↗]`**: 대조 검토 모달을 다시 열어 원문과 결과를 재비교하고 추가 수정
     * **`[복사 ⎘]`**: 최종 완성된 결과문을 즉시 클립보드에 복사
     * **`[파일 열기: ... ↗]`**: 새 파일로 저장된 결과물을 옵시디언 탭에서 즉시 열기
5. **텔레메트리 리소스 확인 & 다음 작업 지시 분리**:
   * 모델명, 응답 시간, 처리 속도(t/s), 토큰 사용량 정보가 접이식으로 깔끔하게 보관됩니다.
   * 작업 세션 바로 밑에는 `──────── 다음 작업 지시 (Next Task) ────────` 구분선과 함께 새로운 입력 폼이 배치되어, 이전 결과와 명확히 구분된 상태로 다음 작업을 곧바로 시작할 수 있습니다.
